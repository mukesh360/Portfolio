About

Who I am and what I work on.

Good AI starts with good data. I work on both halves: getting data clean and dependable, then turning it into features people rely on.

I'm a Data & AI Engineer intern at Markus.ai in Bangalore, and a student of Artificial Intelligence and Data Science at Coimbatore Institute of Technology. Day to day that means Python, SQL, and building out the data and model layers behind AI products.

Outside work I build retrieval-augmented systems end to end: ingestion, chunking, embeddings, vector search, local inference with Ollama, and the FastAPI and Supabase services around them.

Selected work

Projects I have built, with live activity pulled from GitHub.

  • /01

    Featured project

    DocIntel AI

    Multi-agent RAG platform. Each agent gets its own isolated vector store, so a "Legal" agent never answers from a "Study" agent's documents. Answers are grounded strictly in retrieved context and run locally on Ollama.

    • Isolated vector store per agent, no cross-domain answers
    • 5 formats ingested: PDF, DOCX, CSV, TXT, HTML
    • Local inference on Ollama (qwen2.5:7b), with no external LLM API

    FastAPI · LangChain · ChromaDB · Ollama · Supabase
